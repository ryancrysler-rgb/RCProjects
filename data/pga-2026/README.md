# PGA TOUR 2026 shot data (private)

One archive per event: leaderboard.json, cs1-4.json (course stats) and raw/<playerId>-<round>.json (pgatour.com via Parse.bot get_player_shots_compact), every made-cut round. Pulled for internal analysis; the public Tour page publishes only RC Greenlight rates, grades and rankings, never these files.
